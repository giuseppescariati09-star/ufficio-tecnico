# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Apple Native
- **Notes:** iPhone first. Generous spacing, unified corner radii, large titles, inset grouped lists, bottom tab bar, system colors, light and dark themes, native-feeling short transitions.

## Banned anti-aesthetics

- Gratuitous glassmorphism (`backdrop-filter` without a hard edge)
- Neon glowing borders and multi-stop rainbow CTAs
- Floating pastel pill badges for ordinary metadata
- Decorative blob or mesh gradients behind content
- Nested scroll regions
- Cartoon empty-state illustrations
- Huge centered illustration with no CTA
- Icons inside inputs unless functional
- Soft drop-shadows as the only separator
- Disabled primary submit as the only incomplete-form feedback

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** At least 4.5:1 for normal text, 3:1 for large text and borders
- **Touch / focus:** Targets of at least 44×44px, visible focus rings

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Italian. Clear and supportive, like a good colleague: say what is wrong and what to review, without false praise or exclamation marks.

## Icon library

- **Library:** Lucide
- **Package / path:** To be included as local SVG files, so icons work offline. Nothing installed yet.
- **Notes:** One stroke weight. No emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
